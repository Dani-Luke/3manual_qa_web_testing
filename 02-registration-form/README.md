# QA Training Registration Form

Учебный проект по ручному тестированию Web UI. В рамках проекта разработал простую форму регистрации с валидацией пользовательских данных и провел тестирование её функциональности.

## Цель проекта

Цель проекта — получить практический опыт тестирования Web UI и применения техник тест-дизайна:

* Equivalence Partitioning (классы эквивалентности);
* Boundary Value Analysis (анализ граничных значений).

## Функциональность приложения

Форма регистрации содержит следующие поля:

* Username;
* Email;
* Password;
* Age.

После заполнения формы пользователь может отправить данные.

При корректном заполнении всех полей отображается сообщение:

`Registration successful.`

При наличии некорректных данных отправка формы не выполняется, а для соответствующего поля отображается сообщение об ошибке.

## Правила валидации

| Поле     | Требование                                              |
| -------- | ------------------------------------------------------- |
| Username | обязательное поле, от 3 до 20 символов                  |
| Email    | обязательное поле, корректный формат email              |
| Password | обязательное поле, от 8 до 20 символов                  |
| Age      | обязательное поле, целое число от 18 до 65 включительно |

## Тест-дизайн

Для формирования тестовых данных применял:

* классы эквивалентности (Equivalence Partitioning);
* анализ граничных значений (Boundary Value Analysis).

Подробный анализ классов эквивалентности, граничных значений и соответствующих тестовых данных представлен в файле:

[test-design.md](test-design.md)

## Результаты тестирования

В ходе тестирования были проверены:

* корректные значения полей;
* пустые обязательные поля;
* значения за допустимыми границами;
* значения на граничных значениях;
* некорректный формат Email;
* нецелые значения возраста;
* успешная отправка формы;
* отображение сообщений об ошибках.

На момент проведения тестирования критических и функциональных дефектов не обнаружено.

Отдельно отмечено ограничение интерфейса: поле Age использует числовой тип ввода, поэтому некоторые некорректные символьные значения невозможно ввести через пользовательский интерфейс. Это ограничение UI и не является дефектом.

## Запуск приложения

1. Открыть директорию `app`.
2. Запустить файл `index.html` в браузере.
3. Заполнить форму тестовыми данными.
4. Проверить результат отправки и сообщения валидации.

Для запуска приложения не требуется сервер или установка дополнительных зависимостей.

## Вывод

Проект демонстрирует практическое применение техник Equivalence Partitioning и Boundary Value Analysis при тестировании Web UI, а также навыки проверки валидации пользовательских данных, позитивных и негативных сценариев.
