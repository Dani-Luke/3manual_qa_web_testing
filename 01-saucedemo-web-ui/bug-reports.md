# SauceDemo — Баг-репорты

## BUG-01 — Оформление заказа из пустой корзины

**Заголовок:**
Оформление заказа успешно завершается при пустой корзине

**Окружение:**

* Приложение: SauceDemo
* Пользователь: `standard_user`
* Браузер: Chrome
* Операционная система: Windows

**Серьёзность:** Высокая

**Приоритет:** Высокий

**Тип:** Функциональный дефект

**Предусловия:**

* Пользователь авторизован под `standard_user`.
* Корзина пуста.

**Тестовые данные:**

* Имя: `Test`
* Фамилия: `User`
* Почтовый индекс: `12345`

**Шаги воспроизведения:**

1. Открыть корзину.
2. Нажать кнопку перехода к оформлению заказа.
3. В поле `First Name` ввести значение из тестовых данных.
4. В поле `Last Name` ввести значение из тестовых данных.
5. В поле `ZIP / Postal Code` ввести значение из тестовых данных.
6. Нажать кнопку продолжения оформления заказа.
7. На странице проверки заказа нажать кнопку `Finish`.

**Фактический результат:**
Заказ успешно оформляется при пустой корзине. Итоговая сумма заказа составляет 0.

**Ожидаемый результат:**
Оформление заказа невозможно, поскольку корзина не содержит товаров.

## BUG-02 — Несоответствие данных товара

**Заголовок:**
Данные товара в каталоге отличаются от данных на странице товара

**Окружение:**

* Приложение: SauceDemo
* Пользователь: `problem_user`
* Браузер: Chrome
* Операционная система: Windows

**Серьёзность:** Высокая

**Приоритет:** Высокий

**Тип:** Функциональный дефект / несоответствие данных

**Предусловия:**

* Пользователь авторизован под `problem_user`.
* Открыт каталог товаров.

**Тестовые данные:**

* Товар: `Sauce Labs Backpack`

**Шаги воспроизведения:**

1. Найти товар, указанный в тестовых данных.
2. Зафиксировать название, изображение, описание и цену товара в каталоге.
3. Открыть страницу товара.
4. Сравнить название, изображение, описание и цену с данными, зафиксированными в каталоге.

**Фактический результат:**
Данные товара на странице товара отличаются от данных, отображаемых для этого товара в каталоге.

**Ожидаемый результат:**
Данные товара на странице товара соответствуют данным этого же товара в каталоге.
