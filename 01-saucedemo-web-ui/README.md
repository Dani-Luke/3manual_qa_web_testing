# SauceDemo — ручное тестирование Web UI

## О проекте

Учебный проект по ручному тестированию Web UI на примере публичного демонстрационного приложения **SauceDemo**.

В рамках проекта провел исследовательское и функциональное тестирование основных пользовательских сценариев интернет-магазина: от авторизации и выбора товара до оформления и завершения заказа.

Проект подготовлен для портфолио начинающего тестировщика программного обеспечения.

---

## Цель

Проверить работоспособность основных пользовательских функций SauceDemo, выявить функциональные и визуальные дефекты и зафиксировать результаты тестирования в виде QA-артефактов.

---

## Область тестирования

### Проверял

* аутентификация;
* выход из системы;
* каталог товаров;
* сортировка товаров;
* карточки товаров;
* информация о товаре;
* добавление товара в корзину;
* удаление товара из корзины;
* корзина;
* оформление заказа;
* валидация полей оформления заказа;
* обзор заказа;
* расчёт стоимости заказа;
* завершение заказа;
* возврат к товарам;
* PDF-чек;
* основные элементы пользовательского интерфейса.

---

## Подход к тестированию

В проекте использовал:

* функциональное тестирование;
* позитивные проверки;
* негативные проверки;
* проверка пользовательских сценариев;
* проверка валидации;
* проверка взаимодействия элементов интерфейса;
* проверка отображения данных;
* визуальная проверка.

Отдельное внимание уделял сквозному пользовательскому сценарию:

**Авторизация → Каталог → Товар → Корзина → Оформление заказа → Завершение заказа.**

## Тестовые пользователи

Для проверки различных вариантов поведения приложения использовал предоставленные SauceDemo тестовые пользователи:

* `standard_user`
* `problem_user`
* `error_user`

Использование разных пользователей позволило выявить дефекты, проявляющиеся только в отдельных сценариях.

### Основные найденные проблемы

Среди выявленных дефектов:

* оформление заказа при пустой корзине;
* несоответствие данных товара в разных представлениях;
* неправильное изображение товара;
* некорректная сортировка;
* проблемы с полем `Last Name`;
* невозможность завершить оформление заказа;
* отсутствие описания товара.

Все перечисленные дефекты были воспроизведены и зафиксированы в `bug-reports.md`.
