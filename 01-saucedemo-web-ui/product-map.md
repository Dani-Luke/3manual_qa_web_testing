# SauceDemo — Product Map (Карта функциональности)

## 1. Authentication (Аутентификация)

* Login (вход в систему)
* Logout (выход из системы)

## 2. Product Catalog (Каталог товаров)

* All Items (все товары)
* Product Sorting (сортировка товаров)

  * Name A-Z
  * Name Z-A
  * Price low to high (от низкой цены к высокой)
  * Price high to low (от высокой цены к низкой)
* Dynamic Catalog (динамический каталог)

  * Lazy Loading (ленивая загрузка)
  * Loading Spinner (индикатор загрузки)
  * Slider (слайдер)

## 3. Products (Товары)

* Product Card (карточка товара)
* Product Details (детальная информация о товаре)
* Add to Cart (добавление в корзину)
* Remove from Cart (удаление из корзины)

## 4. Cart (Корзина)

* View Products (просмотр товаров)
* Remove Product (удаление товара)
* Continue Shopping (продолжение покупок)
* Checkout (оформление заказа)

## 5. Checkout (Оформление заказа)

### Customer Information (Данные покупателя)

* First Name (имя)
* Last Name (фамилия)
* ZIP / Postal Code (почтовый индекс)
* Required-field Validation (валидация обязательных полей)
* Continue (продолжение оформления)

### Order Overview (Информация о заказе)

* Products (товары)
* Payment Information (информация об оплате)
* Shipping Information (информация о доставке)
* Price Total (итоговая стоимость)

  * Item Total (стоимость товаров)
  * Tax (налог)
  * Total (итоговая сумма)
* Cancel (отмена оформления)
* Finish (завершение заказа)

## 6. Order Completion (Завершение заказа)

* Success Notification (уведомление об успешном завершении)
* Return to Products / Back Home (возврат к каталогу товаров)
* PDF Receipt / Generate PDF Order (PDF-чек / генерация PDF-заказа)

## 7. About (Информация о приложении)

* About page (страница с информацией о приложении)

## 8. Test Utilities (Инструменты для тестирования)

* Reset App State (сброс состояния приложения)
