# SauceDemo — Checklist (Чек-лист)

## 1. Authentication (Аутентификация)

1. Проверить успешный вход с валидными учётными данными.
2. Проверить отображение ошибки при вводе неверных учётных данных.
3. Проверить невозможность входа заблокированного пользователя.
4. Проверить работу Logout (выхода из системы).
5. Проверить, что после Logout пользователь возвращается на страницу авторизации.

## 2. Product Catalog (Каталог товаров)

1. Проверить открытие страницы All Items (все товары).
2. Проверить сортировку товаров по Name A-Z (имя от A до Z).
3. Проверить сортировку товаров по Name Z-A (имя от Z до A).
4. Проверить сортировку товаров по Price low to high (цена от низкой к высокой).
5. Проверить сортировку товаров по Price high to low (цена от высокой к низкой).

## 3. Dynamic Catalog (Динамический каталог)

1. Проверить открытие Dynamic Catalog.
2. Проверить отображение Loading Spinner.
3. Проверить работу Lazy Loading.
4. Проверить работу Slider.

## 4. Products (Товары)

1. Проверить соответствие изображения выбранному товару.
2. Проверить соответствие названия товара в каталоге и на странице товара.
3. Проверить соответствие описания товара в каталоге и на странице товара.
4. Проверить соответствие цены товара в каталоге и на странице товара.
5. Проверить добавление товара в корзину.
6. Проверить изменение кнопки Add to Cart на Remove.
7. Проверить удаление товара через кнопку Remove.
8. Проверить, что после удаления товара корзина возвращается в пустое состояние.

## 5. Cart (Корзина)

1. Проверить отображение добавленного товара в корзине.
2. Проверить корректность названия товара в корзине.
3. Проверить корректность описания товара в корзине.
4. Проверить корректность цены товара в корзине.
5. Проверить удаление товара из корзины.
6. Проверить работу Continue Shopping (продолжения покупок).
7. Проверить переход к Checkout (оформлению заказа).
8. Проверить, что после удаления всех товаров корзина становится пустой.

## 6. Checkout — Customer Information (Оформление заказа — данные покупателя)

1. Проверить ввод валидного First Name (имени).
2. Проверить ввод валидного Last Name (фамилии).
3. Проверить ввод валидного ZIP / Postal Code (почтового индекса).
4. Проверить валидацию пустого First Name.
5. Проверить валидацию пустого Last Name.
6. Проверить валидацию пустого ZIP / Postal Code.
7. Проверить переход к Order Overview (информации о заказе) после заполнения обязательных полей.

## 7. Order Overview (Информация о заказе)

1. Проверить отображение выбранного товара.
2. Проверить корректность названия товара.
3. Проверить корректность описания товара.
4. Проверить корректность цены товара.
5. Проверить отображение Payment Information (информации об оплате).
6. Проверить отображение Shipping Information (информации о доставке).
7. Проверить отображение Price Total (итоговой стоимости).
8. Проверить наличие Item Total (стоимости товаров).
9. Проверить наличие Tax (налога).
10. Проверить наличие Total (итоговой суммы).
11. Проверить корректность Item Total.
12. Проверить корректность Tax.
13. Проверить корректность Total.
14. Проверить работу Cancel (отмены оформления).
15. Проверить, что Cancel не завершает оформление заказа.
16. Проверить сохранение товара в корзине после Cancel.
17. Проверить завершение заказа через Finish.

## 8. Order Completion (Завершение заказа)

1. Проверить отображение сообщения о завершении Checkout.
2. Проверить корректность текста сообщения об успешном завершении заказа.
3. Проверить отображение информации о доставке после завершения заказа.
4. Проверить работу Back Home (возврата к каталогу товаров).
5. Проверить работу Generate PDF (генерации PDF).
6. Проверить скачивание PDF-файла.
7. Проверить наличие информации о заказе в PDF-файле.

## 9. Additional UI Checks (Дополнительные проверки интерфейса)

1. Проверить основные элементы пользовательского интерфейса.
2. Проверить корректность текста на кнопках.
3. Проверить корректность подписей элементов интерфейса.
4. Проверить отображение изображений.
5. Проверить работу основных элементов навигации.
6. Проверить отображение сообщений об ошибках.
7. Проверить отсутствие очевидных визуальных дефектов.

## 10. Test Users (Тестовые пользователи)

1. Проверить основные сценарии с `standard_user`.
2. Проверить поведение приложения с `problem_user`.
3. Проверить поведение приложения с `error_user`.
