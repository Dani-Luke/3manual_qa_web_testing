# Manual QA Portfolio

Учебное портфолио начинающего специалиста в области ручного тестирования ПО.

В репозитории собрал практические проекты, демонстрирующие навыки **Manual QA, Web UI testing и тест-дизайна**.

## Навыки

* функциональное тестирование;
* позитивное и негативное тестирование;
* тест-кейсы и чек-листы;
* баг-репорты;
* классы эквивалентности;
* граничные значения;
* Web UI и Chrome DevTools;
* базовые HTML / CSS;
* Git и GitHub.

## Проекты

Ручное тестирование учебного интернет-магазина.

Проверил основные пользовательские сценарии: авторизация, каталог, товары, корзина, оформление и завершение заказа.
